# AI Health Risk Assessment

เว็บแอประบบประเมินความเสี่ยงด้านสุขภาพเบื้องต้นจากรูปภาพและข้อมูลผู้ใช้ด้วย AI

## วิธีใช้งาน
1. สร้างโปรไฟล์ (หน้าโปรไฟล์)
2. อัปโหลดรูปภาพ (ไม่บังคับ)
3. กรอกข้อมูลสุขภาพ
4. AI ประเมินความเสี่ยงและให้คำแนะนำ

## Tech Stack
- Frontend: React 19 + Vite + TypeScript
- Backend: Hono + Cloudflare Workers + D1
- Deploy: Cloudflare Pages + Workers
